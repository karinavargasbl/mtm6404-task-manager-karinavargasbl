# mtm6404-task-manager-karinavargasbl

Jewelry Task Manager – Iteration 01

A pastel-themed task manager designed for a handmade jewelry business like Del Mar Gems.

This static mockup was built using:
- React 18 via CDN
- JSX with Babel
- Custom pastel CSS (pink and soft tones)
- 5+ components, including:
  - Navbar
  - Sidebar (priority levels)
  - Task list with 5 tasks
  - Footer
